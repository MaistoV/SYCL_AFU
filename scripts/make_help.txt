make targets:

FIM:
    fim_build_pr          Build FIM and PR-tree (takes around 1h45m)
    fim_build_flat        Build flat FIM (takes around 1h10m)
    fim_update            Update flash images on the board (around 2m)
    pac_powercycle_<page> Power cycle from page <user1|user2|factory>, necessary after FIM udpate (fim_update) (waits for 10s)
    opae.io_bind          Bind all VFs to VFIO driver
    opae.io_bind_one      Bind only ${FIRST_AFU_VF} to VFIO driver
    opae.io_relese        Release all VFs from VFIO driver
    pac_hot_plug          Unplug and re-plug PAC from PCIe bus (virtually)

OneAPI ASP flow (Altera OpenCL):
    oneapi_asp_build_aocx Build bitstreaam for ASP
    aocl_aocx_initalize   Program PAC with aocx (requires the right PR interface to be already flashed on the PAC)
    aocl_bsp_build        Build PR-tree related BSP
    aocl_bsp_[un]install  Install/uninstall BSP
    oneapi_asp_<target>   Build oneapi design in ${SYCL_SRC_DIR}, target in: {fpga_emu, fpga_sim, report, fpga}
    test_asp_fpga_emu     Test ASP in emulation
    test_asp_fpga_sim     Test ASP in simulation
    test_asp_fpga          Test ASP on hardware (requires aocl_aocx_initalize)

OneAPI IP flow:
    oneapi_ip_emu         Build oneapi design in ${SYCL_SRC_DIR}, target fpga_emu
    oneapi_ip_report      Build oneapi design in ${SYCL_SRC_DIR}, target report
    oneapi_open_ip_report Open early report in browser 
    oneapi_ip_fpga_emu    Build fpga_emu target
    oneapi_ip_plain_c     Build plain_c (C-only, no SYCL)
    test_ip_fpga_emu      Run fpga_emu binary
    test_ip_plain_c       Run plain_c binary

AFU flow:
    afu_host              Build AFU host application in ${AFU_SW_DIR}
    ase_setup             Setup and launch ASE simulation environment {locks a terminal}
    ase_launch            Subsequent launches of ASE simulator, if the source list of sim config has not changed {locks a terminal}
    ase_waves             Open simulated waveforms in ${AFU_ASE_DIR}/work/vsim.wlf
    gbs                   Build green bitstream (takes around 40 minutes)
    gbs_configure         Configure GBS in PR-slot. On error, you must first make pac_hot_plug
    test_gbs              Run host application against hadware
    test_sycl_afu         Synonim as test_gbs
    test_ase              Run host application against ASE simulator (requires make ase_setup or make ase_launch in another terminal)

Measure targets:
    measure_asp_plain_c  Run measures for plain C implementation of SYCL code
    measure_isal         Run measures for ISA-L
    measure_asp_fpga     Run measures for ASP SYCL flow (also triggers asp_fpga to rebuild)
    measure_sycl_afu     Run measures for AFU SYCL flow (only a single-threaded AFU)
    measure_all          Run all of the above 
    measure_plots        Run data plot scripts

Clean targets:
    clean_fim_pr          Clean FIM PR build
    clean_fim_flat        Clean FIM flat build
    clean_oneapi_asp      Clean OneAPI ASP build
    clean_oneapi_ip       Clean OneAPI IP build
    clean_oneapi_ip_report Clean only generated and exported OneAPI IP 
    clean_afu_host        Clean AFU host software
    clean_gbs             Clean gbs build
    clean_ase             Clean ASE simulator setup
    clean_sw              Clean software build
    clean_measure         Remove old measures
    clean_all             TBD

make variables:
    RS_SCHEMA             [RS] Reed-Solomon code schema in [RS_3_2, RS_6_3, RS_10_4]
    FIM_IMAGE             [FIM] Override default FIM image for fim_update
    TEST_ARGS             [Host] Arguments to pass to the host elf in oneapi_ip_emu, test_gbs and test_ase, start with -h
    MULTI_ERASURE_SIMPLE  [Host] Enable multi-erasure SYCL host code when setting up SYCL build
    OFSS_CONFIG           [FIM] Suffix to identify FIM build and OFSS flow
    UPDATE_DEFAULT_AFU    [FIM] For FIM PR or flat builds, build ${AFU_NAME} in FIM afu_main
    FIM_NUM_PF0_VFS       [FIM] Select OFSS configuration by the number of PF0 VFs, i.e. AFU's
    RESEED_FITTER         [FIM] Randomly reseed fitter for FIM builds
    AFU_MAX_NUM           [FIM/GBS] Override default number of AFUs for AFU arrays
    AFU_MAX_NUM           [AFU] Override number of used VFs, defaults to ${FIM_NUM_PF0_VFS}
    ACL_DEVICE            [ASP] Override default acl device for aocl_aocx_initalize
    SYCL_FAST_COMPILE     [SYCL] Set -Xsfast-compile for SYCL builds
    SYCL_CMAKE_FLAGS      [SYCL] Add user cmake flags for SYCL builds
    MMD_DEBUG             [Debug] Enable debug mode for OneAPI/OpenCL MMD driver
    RSU_DEBUG             [Debug] Enable debug mode for RSU operation (pac_powercycle_*)
    FIM_UPDATE_DEBUG      [Debug] Enable debug mode for fpgasupdate operation (fim_update, gbs_config)
    SYCL_DEBUG            [Debug] Enable debug mode for SYCL builds
